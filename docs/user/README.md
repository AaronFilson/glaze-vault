# Glaze Vault user guide

Glaze Vault keeps your glaze and clay recipes encrypted on your own computer, phone or tablet, and
works out each glaze's and clay body's chemistry as you type, with the same calculator as
[Glazecalc](https://glazecalcapp.com). There is no account and no cloud, and no internet connection
is needed: the only thing Glaze Vault ever asks the internet is whether there is a newer desktop
version, and you can turn that off.
